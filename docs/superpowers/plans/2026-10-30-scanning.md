# Scanning Through Image Capture Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** HP USB printers with an LEDM scanner show up in Image Capture and Preview and scan, through a loopback-only eSCL bridge agent.

**Architecture:** A per-user LaunchAgent, `smudge-scand`, serves eSCL on
`127.0.0.1` and announces `_uscan._tcp` on the local-only Bonjour
interface. It translates eSCL jobs into LEDM scan jobs over the
printer's ff/cc/0 USB interface. The app keeps the 255/4/1 interface
for ink and maintenance. Shared USB and LEDM code moves into a library
both executables link. Pure translation logic lives in its own library
so it can be tested without hardware.

**Tech Stack:** Swift 6 toolchain in Swift 5 language mode, SwiftPM,
IOKit/IOUSBHost, Network.framework (`NWListener`), dnssd
(`DNSServiceRegister`), SystemConfiguration (console user), ImageIO
and CoreGraphics (encoding, PDF), XCTest.

**Spec:** `docs/superpowers/specs/2026-10-30-scanning-design.md`, with
the printer's capabilities in
`docs/superpowers/specs/2026-10-30-scanning-scancaps-deskjet-2300.xml`.

## Global Constraints

- No new package dependencies. Only macOS system frameworks.
- The listener binds `127.0.0.1` only. Bonjour registers with `kDNSServiceInterfaceIndexLocalOnly` only. Nothing may be reachable from the LAN.
- The agent uses only USB interfaces of class 255, subclass 0xcc (204), protocol 0. It never opens 255/4/1 or the printer class interface.
- The agent holds no USB interface while no request or job is running.
- Deployment target stays `.macOS(.v14)`. Swift language mode `.v5` for every target, as in `app/Package.swift`.
- Every new source, script and plist starts with `SPDX-License-Identifier: AGPL-3.0-or-later` and `Copyright (C) 2026 Gamunu Balagalla` (`scripts/check-spdx.sh` enforces it).
- eSCL units are 1/300 inch and LEDM geometry is 1/300 inch. No conversion between them.
- Bonjour TXT: `txtvers=1 vers=2.63 rs=eSCL ty=<name> pdl=<formats> cs=color,grayscale,binary is=platen uuid=<uuid> duplex=F representation= note=`.
- User-visible copy: plain words, no em or en dashes.
- Commits: Conventional Commits, GPG-signed, no AI attribution.

## Review Focus

1. **A 1200 dpi full-glass color scan.** It takes minutes and is about 400 MB raw. Image Capture must not time out waiting on `NextDocument`, and the agent must not hold the page in memory. Owner: Task 7 (streaming plus a hardware timing test).
2. **Image Capture cancels mid-scan** (Cancel button, or the window closing). The LEDM job must be canceled with a PUT, the interface released, and the next scan must work. Owner: Task 6 (router test) and Task 7 (hardware check).
3. **The printer is unplugged mid-scan.** The job must end with an error state, not hang. The Bonjour record must go away, and replugging must bring it back. Owner: Task 8 (watcher test with a fake device) and Task 11 (hardware).
4. **Scan area at the glass edge or rounded oddly.** For example A4 width 2480 against max 2550, or a crop whose offset plus width exceeds the max by 1. Clamp off-by-one overshoots, reject real out-of-range regions with 400, and never send the printer an area it rejects. Owner: Task 4 (settings validation tests).
5. **Two scans requested back to back,** for example an overview scan then a real scan before the first job is deleted. The second gets 503 while the first runs, and works once it ends. Owner: Task 6 (router test).

Required content, from the spike (spec, "What we know"). The capabilities XML has the namespaces `scan=http://schemas.hp.com/imaging/escl/2011/05/03` and `pwg=http://www.pwg.org/schemas/2010/12/sm`, plus:
- `pwg:Version 2.63`, MakeAndModel, SerialNumber and `scan:UUID`
- Platen `Min/MaxWidth`, `Min/MaxHeight`, `MaxPhysicalWidth/Height` (from the max), and `MaxScanRegions 1`
- ColorModes for each LEDM color type present (`K1` gives BlackAndWhite1), and `ColorSpaces sRGB`
- DocumentFormats as both `pwg:DocumentFormat` and `scan:DocumentFormatExt`, discrete resolutions, and `MaxOpticalX/YResolution`
- SupportedIntents `Document, TextAndGraphic, Photo, Preview`
- `BrightnessSupport`, `ContrastSupport`, `SharpenSupport` and `ThresholdSupport`, each with `Min 0`, `Max 2000`, `Normal 1000`, `Step 1`

The status XML is `pwg:Version 2.63` and `pwg:State`, then `scan:Jobs` with one `scan:JobInfo` per job. Each JobInfo holds `pwg:JobUri /eSCL/ScanJobs/<id>`, `pwg:JobUuid`, `scan:Age`, `pwg:ImagesCompleted`, `pwg:ImagesToTransfer`, `pwg:JobState` and `pwg:JobStateReasons/pwg:JobStateReason` (`JobScanning`, `JobCompletedSuccessfully`, `JobCanceledByUser`).

Planner rules (spec, mapping table):
- RGB24 gives Color. Grayscale8 and BlackAndWhite1 give Gray.
- The device format is Raw when the output is png or tiff, or when the mode is BlackAndWhite1. Otherwise it is Jpeg.
- When `tone.deviceApplies` is false, brightness and contrast go into `PostProcess.softwareBrightness/softwareContrast` and the device gets `neutral`. When it is true, they go into the request and the software fields stay nil.
- A page with no post steps whose output is jpeg is passed through untouched.
- Threshold maps 0..2000 to 0..255, with 1000 as 128.
- Sharpen 1000 means none. Above 1000 is an unsharp mask (CoreImage `CIUnsharpMask`, intensity `(v-1000)/1000`, radius 1.5 px at 300 dpi scaled by resolution). Below 1000 is a light blur, the same scale.
- Every output carries the scan resolution in its metadata (DPI). A PDF page is sized `width/res × height/res` inches.

Routes:
- `GET /eSCL/ScannerCapabilities` returns 200 with the caps XML.
- `GET /eSCL/ScannerStatus` returns 200. `device.scannerState()` is called at most once every 3 s, cached otherwise, and is never called while a job runs (then the state is `Processing`). `Idle` maps to `Idle`, a USB error to `Stopped`, anything else to `Processing`.
- `POST /eSCL/ScanJobs`: 400 for a parse or validation error. 503 while a job runs, or when the device state is not Idle. Otherwise 201 with `Location: /eSCL/ScanJobs/<id>`. The scan runs on a background queue: `device.scan`, then `ImagePipeline.render`, then the waiter resolves.
- `GET /eSCL/ScanJobs/<id>/NextDocument`: the first call returns `.pending(waiter)`. After the page has been sent, it returns 404. An unknown id returns 404.
- `DELETE /eSCL/ScanJobs/<id>`: sets the job's cancel flag, the device sends the LEDM cancel, the job state becomes canceled, and the route returns 200.
- Any other path returns 404.
